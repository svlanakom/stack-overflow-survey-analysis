# Stack Overflow Developer Survey – Data Analysis

## Project Overview
This project analyzes the Stack Overflow Developer Survey dataset using Python and Pandas.  
The goal was to explore developer experience, remote work trends, Python popularity, and salary distributions across countries.

## Dataset
- Source: Stack Overflow Developer Survey 2025  
- Rows: 49,191 respondents  
- Columns: 172 variables  

## Tools & Technologies
- Python  
- Pandas  
- Jupyter Notebook  

## Key Analysis Performed
- Calculation of total respondents
- Analysis of response completeness
- Statistical analysis of work experience (mean, median, mode)
- Remote work distribution
- Percentage of Python developers
- Salary analysis by country (mean and median compensation)
- Education level analysis of top earners
- Filtering and grouping with Pandas
- Handling missing values

## Key Insights
- Identified distribution of developer experience levels
- Analyzed compensation differences across countries
- Evaluated Python popularity among respondents
- Explored trends in remote work

## How to Run
1. Download the dataset files.
2. Open the Jupyter Notebook.
3. Run all cells to reproduce the analysis.
